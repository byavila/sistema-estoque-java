\# Sistema de Estoque



Sistema de gerenciamento de estoque desenvolvido em Java com integração ao banco de dados MySQL utilizando JDBC.



\## Objetivo



Projeto desenvolvido para praticar programação orientada a objetos, integração com banco de dados e operações CRUD.



\## Funcionalidades



\- Cadastro de produtos.

\- Listagem de produtos.

\- Busca de produtos por ID.

\- Atualização de produtos.

\- Exclusão de produtos.

\- Validação de dados.

\- Tratamento de exceções.



\## Tecnologias utilizadas



\- Java

\- MySQL

\- JDBC

\- Eclipse

\- Git



\## Conceitos aplicados



\- Programação Orientada a Objetos (POO).

\- Encapsulamento.

\- Padrão DAO.

\- Collections.

\- PreparedStatement.

\- ResultSet.

\- Tratamento de exceções.

\- Variáveis de ambiente.



\## Como executar



1\. Clone ou baixe o repositório.

2\. Importe o projeto no Eclipse.

3\. Baixe o MySQL Connector/J 26.10.0 e coloque o arquivo JAR na pasta lib (crie a pasta caso não exista).

4\. Execute o arquivo database.sql no MySQL.

5\. Configure as variáveis de ambiente DB\_URL, DB\_USER e DB\_PASSWORD.

6\. Execute a classe Main.
